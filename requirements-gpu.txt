# equity_strategy/32-35, "Strategy 8" -- see the README's "Options-strategy GPU roadmap" and
# "Equity-strategy GPU roadmap" sections). Install alongside requirements.txt:
#   pip install -r requirements.txt -r requirements-gpu.txt
#
# Deliberately pip-only, no conda/RAPIDS -- see the README's "GPU library choice" note for why.
# torch and cupy both need a build matching the machine's actual CUDA version:
#   - torch: pick the index URL for this machine's CUDA from https://pytorch.org/get-started/locally/
#       e.g. pip install torch --index-url https://download.pytorch.org/whl/cu124
#   - cupy: package name encodes the CUDA major version, e.g. cupy-cuda12x for CUDA 12.x
#       (check with `nvidia-smi`, then see https://docs.cupy.dev/en/stable/install.html)
# The plain `torch`/`cupy-cuda12x` lines below assume a recent CUDA 12.x driver (typical for a
# 5090); override them explicitly if the 5090 box turns out to have a different CUDA version.
# equity_strategy/33_gpu_walkforward_signal.py's MLP is hand-rolled directly against the cupy/numpy
# backend (not torch) specifically so the equity GPU pipeline needs nothing beyond cupy here --
# torch below is only required for options_strategy/44_ml_contract_selector.py.
