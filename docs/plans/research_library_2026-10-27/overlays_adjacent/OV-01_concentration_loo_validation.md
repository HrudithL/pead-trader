# OV-01: Concentration and leave-one-out stress tests as a standard validation

- Status: planned | Priority: P0 | Effort: M | Date: 2026-10-27
- Sources: library `strategies/20_FACTOR_BACKTESTER_CONCENTRATION.md`, `audits/06_ADJACENT_CODE_AND_REPORT_DISCREPANCIES.md` section E, `comparisons/03_EVIDENCE_GRADING_AND_COMPARABLE_BACKTESTS.md` ("Matched-capital experiment": remove strongest ticker, best year, hottest quarter, strongest sector), `strategies/14_VOLATILITY_REGIME_MOMENTUM.md` section 9 (market-group removal), `reproduction/04_PAIRED_FACTOR_AND_RISK_ABLATIONS.md` section 6 (log all variants tried).

## 1. Thesis & what we take from source (and what we do NOT take)

Thesis: a long-only top-decile book can look good because of a handful of names, one year or one sector (the repo already knows its alpha is partly "event universe", `docs/STEADY_DRIFT.md` placebo section). Every overlay in OV-02..OV-07 must be judged against concentration, so this is a validation tool, not a return idea. It is the only P0 item because it costs no research risk and gates the rest.

Take: the procedure (re-run the whole strategy with one name / year / sector removed, report delta CAGR / Sharpe / drawdown / alpha sign; report top-N share of P&L).
Do NOT take: the source's retrospective 20-name universe or its NVDA numbers (37.01% CAGR to 26.10% without NVDA are a statement about 20 hand-picked survivors). Do not copy any pass threshold from a source; none is given.

## 2. Evidence grade & known defects in source

Library grade B for the source repo (code inspectable) but the only quantitative content is one leave-one-out (NVDA, roughly 280x price move, Sharpe 1.21 to 0.93). Universe of 20 current large caps = survivorship; no statistical test. The value is the protocol, which is also endorsed in library audit 06 E.3 and comparison doc 03. Defect to avoid: removing the top contributor chosen ex post is a deliberately adversarial test, not an unbiased estimate; label results "stress", not "out-of-sample".

## 3. Exact rules (codeable)

Inputs: a registered equity strategy `S`, the `EquityUniverse` (`load_equity_universe()`), and a baseline run.

Tier A, static concentration (no re-run), from `results/<name>/positions.parquet` (columns come from `run_equity_backtest`: `permno, day0_date, ann_quarter, ff12_sector, size_quintile, notional, gross_pnl, cost, net_pnl, ret_on_notional`):
1. `share_topN = sum(top N net_pnl by permno) / sum(net_pnl)` for N in {1, 5, 10, 20, 50}; permno-level, not position-level, because one name reports many quarters.
2. `HHI_pnl` of positive net P&L by permno, by year of `day0_date`, by `ff12_sector`.
3. Share of total net P&L from the best year and best 4 consecutive quarters; count of positions needed for 50% of positive P&L.
4. Pareto statistic: fraction of positions with `net_pnl > 0`, mean/median `ret_on_notional`.

Tier B, exact re-run with an exclusion mask `m(events) -> bool array` (True = drop event; its weight is set to 0 BEFORE the engine runs, so first-come-first-served admission and the 5%-ADV / cash cap react as if the event never existed):
- LOO-name: the K=25 permnos with the largest Tier-A net P&L (ex post, by design) plus 25 random permnos from the traded set (seeded) as the control distribution.
- LOO-year: drop all events with `day0_date.year == y` for each year in the sample.
- LOO-quarter: drop `ann_quarter == q` for each quarter (about 72); report the worst 5.
- LOO-sector: drop each `ff12_sector`; LOO-size: drop each `size_quintile`.
- Cumulative top-k removal: drop the top 1, 5, 10, 20 P&L names together.
For each run record: CAGR, vol, Sharpe, max drawdown (`pead.core.metrics.summarize`), alpha and t (`pead.core.alpha.alpha_stats`), n_positions, average risk exposure.

Pass rules are RELATIVE and pre-registered: (a) candidate overlay's `share_top10` and worst single-name delta Sharpe must not be worse than the baseline `steady_drift_plus` by more than the baseline's own seed-to-seed spread on the 25 random-name control (reported before any candidate is judged); (b) alpha t stays > 0 and CAGR stays > T-bill average for every single-name and single-year removal; (c) report, do not threshold, the sector/year results. Absolute cut-offs are NOT fixed here because there is no evidence to calibrate them; the first run on `steady_drift_plus` fixes the reference distribution.

Reporting: one table per strategy written to `results/<name>/stress.csv` plus a section in the per-strategy report; leaderboard untouched.

## 4. Data requirements & availability in THIS repo

All available: `uni.events` has `permno, ff12_sector, size_quintile, ann_quarter, day0_date`; `results/<name>/positions.parquet` is git-ignored but regenerated by `python -m pead run <name>` (REPO_MAP; ARCHITECTURE "Results layout"). Engine speed 1-3 s per equity run (ARCHITECTURE "How the work is parallelized"), so about 150-200 re-runs is roughly 5-10 minutes sequentially. No ETF/other-market data needed. Limitation: permno universe is 6,547 names in `equity_vol_panel.parquet` (verified), so "NVDA-like" single-name dominance is less likely than in a 20-name test; the interesting results are year / quarter / sector.

## 6. Acceptance tests

- Synthetic panel (helper pattern `tests/test_steady_drift.py::_panel`): 4 events, one with +100% return, others +1%; assert `share_top1 > 0.9`; assert LOO of that permno gives CAGR delta matching a run on the 3-event table exactly (equal NAV arrays).
- `event_mask=None` and all-False mask give bit-identical NAV to current `backtest` (regression).
- Determinism: same seed gives identical `stress.csv` (hash); different seed changes only the random-control rows.
- Masks are explicitly ex post (diagnostic only). Test that no registered strategy ever passes `event_mask` internally (grep-style test over `pead/strategies/`), so a mask can never leak into a tradable rule.
- Admission effect: removing a name frees cap room for later events (assert `n_positions` of the rest is >= baseline minus removed).

## 7. Experiment plan

Baselines (results/leaderboard.md, window 1995-2013 incl. flat months): `steady_drift_plus` 12.07% / vol 9.97% / Sharpe 1.19 / DD -22.07%; `steady_drift` 10.59% / 1.16 / -20.00%; `steady_drift_calm` 9.55% / 1.21 / -15.90%; `steady_drift_core` 11.99% / 0.93 / -40.47%. Run stress on all four, then on every OV candidate that survives its own gate. Search window vs holdout: not applicable (no fitting); but report the era tables 1997-2001 / 2002-07 / 2008-13 (existing convention in docs/STEADY_DRIFT.md) for each removal. Ablation: compare against the shuffled-SUE placebo's own LOO to see whether concentration is a property of the universe (REF-placebo).

## 8. Expected outcome and honest risks

Expected: Steady Drift is diversified at the name level (thousands of positions) so single-name removals should barely move it; year and sector removals (2008-09, 1999-2000) will show the real dependence. Risk: false comfort. Single-name LOO says nothing about a regime change in the small/mid-cap event universe (already the main caveat). Multiple-testing: ~150 runs per strategy are descriptive, not hypothesis tests; do not count them as evidence for an edge. Cost: negligible.
