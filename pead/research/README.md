# Research archive

The original numbered scripts (01-53) the project was built with. **Nothing imports from here and none of it is
maintained.** Strategies are now `pead/strategies/*`, the data builds are `pead/prep/`, reports are generated by
`pead/reporting/`. Scripts are kept, with their numbers (which encode the order the work was done and are cited
in the original reports), because they are the record of *why* each design exists and several carry the long
docstrings explaining a bug found or an idea rejected.

Each script's imports were updated for the new package layout (`pead.common.*`, domain `lib/` shims) so most still run
from the repo root, but they write their old-style outputs to `data/` and are superseded by the framework.

**Not ported, deliberately:**

* **Strategy 8** (walk-forward MLP blend of SUE rank and trailing features, GPU parameter search): its committed result (3.5%/yr, Sharpe 0.93) is below Strategy 6, its
  inputs (`equity_feature_panel`, `equity_ml_signal`) are not part of the current prep graph, and its status was already recorded as unverified. If revived, port it as an
  `EquityStrategy` whose `weights()` reads the walk-forward score as a column.
* **Options Tiers 2-4** (exit-rule optimizer, ML contract selector, joint optimizer): built for a GPU box that was never used for a real run, and all were tuned on the original quote
  convention that overstated option returns (STRATEGIES.md section 4.3). Re-run them against the corrected marking before relying on any of their results.
* **The near-ATM options book** (script 40) and the **vol-conditioned Kelly variants** (46-50 with `--vol-conditioned`, 53): negative or superseded results, recorded in their docstrings.
